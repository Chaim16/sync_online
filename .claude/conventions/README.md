# 项目规范文档

本目录包含项目开发过程中需要遵循的各项规范，确保代码质量和团队协作效率。

## 规范文档列表

| 规范 | 说明 |
| --- | --- |
| [命名规范](naming.md) | 统一的项目命名约定，涵盖后端、前端、数据库等 |
| [接口规范](api.md) | HTTP接口设计、请求参数、返回数据等规范 |
| [日志规范](logging.md) | 日志组件使用、日志级别、日志内容等规范 |
| [Git提交规范](git-commit.md) | Git commit message 格式约定 |

## 遵循规范的好处

- **一致性**：统一的代码风格和接口格式，降低维护成本
- **可读性**：清晰的命名和规范的日志，便于代码理解和问题排查
- **协作效率**：标准化的提交信息和接口定义，提升团队协作效率

## 使用方式

在开始任何开发任务前，请先阅读相关规范文档。如有疑问或需要新增规范，请与团队沟通。
